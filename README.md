# KenRelief finished ad videos - TEMPORARY holding spot

Finished ad videos land here (squeezed to under 100 MB) so Facebook can pull them
with no Mac. Every day, a cleanup task copies them into the right Google Drive
folders, checks the copy, and then empties this spot.

- videos/   the finished videos waiting to be copied to Drive
- MANIFEST.tsv   one line per video: where it must go in Drive

Nothing here is the master copy. Drive is the master.
